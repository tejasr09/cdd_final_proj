# ADR-030: Evidence-backed claims only

- Status: accepted
- Date: 2026-11-07
- Decision owners: TODO(human)
- Source: `agent-brief-continuation.md`, D30

## Context

The project is assessed on engineering and research evidence, so unsupported claims would undermine academic integrity.

## Decision

Back personas, interviews, usability scores, benchmarks, deployments, screenshots, and CI claims with actual evidence. Mark absent evidence `TODO(human)` or personas `HYPOTHESIS — to be validated`. Label Appendix C data as synthetic and illustrative.

## Alternatives considered

- Presenting assumptions or generated artifacts as observed findings was rejected as fabricated evidence.

## Consequences

Progress reports must distinguish implemented, measured, planned, and human-provided evidence.
