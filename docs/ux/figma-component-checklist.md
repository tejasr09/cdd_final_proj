## Foundations

- [ ] Typography scale and readable line lengths.
- [ ] Spacing and layout grid.
- [ ] Color tokens with contrast checks.
- [ ] Impact-level tokens: low, moderate, high, critical.
- [ ] Entity-type markers and non-color cues.
- [ ] Focus, hover, pressed, disabled, error, and success states.
- [ ] Reduced-motion behavior if motion is used.
- [ ] Responsive frame sizes and minimum supported width.

## Components

- [ ] App header, organization selector, navigation, account menu.
- [ ] Buttons, links, text fields, text areas, numeric inputs, selects, date/time fields.
- [ ] Entity picker and relationship direction preview.
- [ ] Search/filter/sort controls and tables.
- [ ] Status, severity, review, confidence, and impact badges with text labels.
- [ ] Alerts for estimates, incomplete results, and hypothetical scenarios.
- [ ] Empty, loading, error, permission-denied, and confirmation states.
- [ ] Dialogs and accessible form validation.
- [ ] Graph node/edge treatments, legend, and list/table alternative.
- [ ] Path detail and baseline/scenario comparison rows.

## Required frames

- [ ] Dashboard, populated and empty.
- [ ] Event list, create/edit, and event detail with triggers.
- [ ] Entity list/detail and dependency list/editor.
- [ ] Analysis setup, completed results, incomplete results, and entity detail.
- [ ] Scenario setup, intervention editing, and comparison.
- [ ] Administration with permission-appropriate controls.
- [ ] Mobile/narrow and desktop layouts for primary journey.

## Prototype path

- [ ] Create/open event → choose triggers → save.
- [ ] Inspect or create source → target dependency.
- [ ] Configure and run analysis.
- [ ] Inspect an impact path and confidence reason.
- [ ] Add a hypothetical intervention.
- [ ] Compare baseline and scenario with live-data-unchanged notice.

## Accessibility and evidence

- [ ] Semantic heading order and keyboard path noted.
- [ ] Graph has an accessible list/table alternative.
- [ ] Contrast checked; color is not the only signal.
- [ ] Every frame is labelled draft/validated appropriately.
- [ ] Research findings are traceable to genuine anonymized evidence.
- [ ] No fabricated usability score, quote, or finding.
